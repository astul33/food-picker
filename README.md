# 🥗 تحدي الطبق الصحي (Healthy Plate Challenge)

لعبة تفاعلية تعليمية مصممة للسبورات الذكية والشاشات المدرسية والأجهزة اللوحية، للتنافس بين فريقين في تركيب أطباق غذائية صحية ومتوازنة وفق معايير التغذية السليمة المعتمدة عالمياً.

---

## ✨ المميزات الرئيسية
- **مكتبة أطعمة ضخمة (+85 صنفاً غذائياً)** تغطي جميع المجموعات الغذائية الست:
  1. 🥦 **الخضروات**: بروكلي، جزر، سبانخ، طماطم، خيار، أفوكادو، فلفل رومي، باذنجان، كوسة، فطر، بازلاء، قرنبيط، شمندر، والمزيد.
  2. 🍎 **الفواكه**: تفاح، موز، برتقال، تمر، فراولة، بطيخ، مانجو، توت أزرق، أناناس، رمان، كيوي، تين، خوخ، كرز، كمثرى.
  3. 🌾 **الحبوب والنشويات الكاملة**: أرز بني، خبز بر كامل، شوفان، بطاطا حلوة، كينوا، معكرونة قمح كامل، فريك، برغل، فشار صحي.
  4. 🍗 **البروتينات الصحية**: سلمون، سمك مشوي، بيض مسلوق، دجاج مشوي، عدس، حمص، فول، تونة، مكسرات ولوز نيء، روبيان، توفو.
  5. 🥛 **الألبان ومنتجاتها**: حليب طازج، زبادي يوناني، لبنة بزيت الزيتون، لبن عيران، جبن قريش، كفير، حليب نباتي مدعم.
  6. ⚠️ **الأطعمة غير الصحية (للتوعية والخصم)**: مشروبات غازية، شيبس، دونات، بطاطس مقلية، برجر، نودلز سريعة، حلويات مصنعة.
- **محرك تقييم غذائي ذكي**:
  - احتساب مكافأة التنوع (حتى +70 نقطة عند تغطية المجموعات الـ 5 الأساسية).
  - مكافأة السرعة للأطباق الصحية السريعة.
  - خصم 20 نقطة لكل عنصر غير صحي مع تقديم نصائح توجيهية مخصصة.
- **محرك بحث وتصنيف فوري**: شريط بحث سريع مع أزرار تصفية وعدادات لكل تصنيف.
- **دعم كامل للسبورات التفاعلية**: سحب وإفلات (Drag & Drop) ولمس مباشر (Click to Add).
- **نظام تحكيم وجولات تفاعلي**: تحكم بعدد الجولات، زمن المؤقت، جولة الحسم الفاصلة في حالة التعادل، ومؤثرات صوتية مميزة.

## 🚀 خطوات النشر على Vercel (How to Deploy to Vercel)

المشروع جاهز 100% للنشر الفوري على منصة **Vercel**:

### الطريقة الأولى: عبر لوحة تحكم Vercel (مستحسن)
1. ارفع المشروع إلى حسابك في **GitHub** أو **GitLab** أو **Bitbucket**.
2. توجّه إلى موقع [vercel.com](https://vercel.com) وسجّل الدخول.
3. اضغط على **"Add New..."** ثم اختر **"Project"**.
4. اختر المستودع الخاص بك واضغط على **"Import"**.
5. الإعدادات الافتراضية محددة مسبقاً وتعمل تلقائياً بفضل ملف `vercel.json`:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build` أو `vite build`
   - **Output Directory**: `dist`
6. اضغط على **"Deploy"**، وخلال أقل من دقيقة سيكون موقعك نشطاً ومتاحاً عبر رابط عالمي سريع ومجاني!

### الطريقة الثانية: عبر Vercel CLI (سطر الأوامر)
إذا كان لديك أداة `vercel` مثبتة:
```bash
# تسجيل الدخول
npx vercel login

# النشر المباشر
npx vercel --prod
```

## 🛠️ التشغيل والتطوير المحلي (Local Development)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# فحص الأخطاء البرمجية
npm run lint

# بناء نسخة الإنتاج
npm run build

# معاينة نسخة الإنتاج
npm run preview
```
